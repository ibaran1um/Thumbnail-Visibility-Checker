# サムネ視認性チェッカー（Thumbnail-Visibility-Checker）

サムネイルや配信オーバーレイの画像を読み込むと、次の4つをまとめて確認できるブラウザツールです。

1. **小さく表示したときの見え方** — 一覧表示を想定した幅で、実際の大きさで並べて表示
2. **色の見え方・明るさ** — 色覚特性（1型・2型・3型）のシミュレーション、明るさのみ、ぼかし
3. **文字と背景のコントラスト比** — 画像をクリックして色を拾い、WCAG 2.x の基準で判定
4. **重なり領域** — 再生時間表示などが重なりやすい場所を画像の上に表示

結果は1枚の比較シート（PNG）として保存できます。

**画像はブラウザの中だけで処理され、外部には送信されません。** サーバー・データベース・ログインは使っておらず、外部のライブラリやフォントも読み込みません。

## 使い方

1. ページを開き、画像をドロップするか「ファイルを選ぶ」で読み込みます（Ctrl+V／⌘+V で貼り付けも可）。
2. 「1. 小さく表示したときの見え方」で、文字が潰れていないか確認します。表示幅は「表示幅のプリセットを編集」で変更できます。
3. 「2. 色の見え方・明るさ」で、色の違いだけに頼った配色になっていないか確認します。
4. 「3. コントラスト比」で、画像上の文字の中央をクリック → 背景をクリックすると、コントラスト比と合否が表示されます。色コードを直接入力することもできます。
5. 「4. 重なり領域」の赤い枠に、大事な文字や顔がかかっていないか確認します。位置と大きさは％で調整できます。
6. 「PNGで保存」で比較シートを保存します。

表示幅と重なり領域の設定は、このブラウザの localStorage に保存されます（使えない環境では保存されないだけで、動作には影響しません）。

## 公開方法（GitHub Pages）

このリポジトリのファイルをそのまま置き、Settings → Pages で公開元のブランチ（ルート）を指定すれば動きます。ビルドは不要です。

## 仕組みと根拠

- **縮小表示**：Canvas で段階的に半分ずつ縮小し、最後に目的の幅へ縮めています。画面の拡大率（devicePixelRatio）に合わせて描くため、表示中の画面での実寸に近い見え方になります。
- **色覚シミュレーション**：いずれも線形RGBで計算し、色の区別がもっとも難しい場合（2色覚）を再現しています。あくまで近似で、実際の見え方には個人差があり、より軽い特性の人の方が多いことにも注意してください。
  - 1型・2型：Machado, Oliveira & Fernandes (2009) "A Physiologically-based Model for Simulation of Color Vision Deficiency"（IEEE TVCG）の強度1.0の変換行列。係数は原著者ページの Table 1 と一致することを確認しています。
  - 3型：Brettel, Viénot & Mollon (1997) "Computerized simulation of color appearance for dichromats"。Machado (2009) は3型の再現性が低いとされているため、こちらを採用しています。定数は [DaltonLens-Python](https://github.com/DaltonLens/DaltonLens-Python)（MIT License）の実装から算出しました。
  - 検証：4096色の格子画像とサンプル画像で、DaltonLens-Python の同じモデルの出力と比べ、全画素の差が1/255以内（丸め誤差）であることを確認しています。
- **コントラスト比**：WCAG 2.x の相対輝度とコントラスト比の定義に従って計算しています。基準を満たさない値が合格に見えないよう、表示は小数第2位で切り捨てています。
- **ぼかし**：いったん縮小してから拡大する方式です。ブラウザごとの Canvas フィルター対応差に影響されません。

## 注意・未確認の点

- 「小さく表示」の幅と「重なり領域」の位置は**目安**です。各サービスの実際の表示サイズや表示位置は、端末・画面・仕様変更によって変わるため、実際の表示に合わせて調整してください。
- コントラスト比の基準（WCAG）はWebページ向けのものです。サムネの読みやすさの目安として使っています。
- 縁取りや影つきの文字は、文字色と背景色だけでなく、縁取り色と背景色の組み合わせも確認してください。
